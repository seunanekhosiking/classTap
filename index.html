COMMON QUESTIONS

Before you ask.

Does ClassTap replace SA-SAMS?+

No. ClassTap makes daily capturing easier while SA-SAMS remains the school’s core information system.

Do we import learners and teachers?+

No duplicate setup is required. ClassTap uses learner, educator and class information already available at the school.

What happens when Wi-Fi is interrupted?+

The attendance module saves work safely on the device and sends it when the school system becomes available.

Can teachers use their phones?+

Yes. ClassTap is designed for Android phones, tablets and Windows computers, with broader platform support planned.
